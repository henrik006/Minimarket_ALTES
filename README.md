# Minimarket ALTES

## Descripción
Sistema de gestión para el minimarket ALTES,
desarrollado como proyecto académico.

## Tecnologías
- Python
- HTML
- SQLite
- Visual Studio Code

## Funcionalidades
- Gestión de productos.
- Gestión de empleados y usuarios.
- Registro y administración de ventas.
- Gestión de inventario.
- Administración de información del minimarket.

## Instalación y ejecución
1. Instalar Python.
2. Descargar o clonar el repositorio.
3. Revisar las dependencias necesarias.
4. Ejecutar el archivo app.py.
